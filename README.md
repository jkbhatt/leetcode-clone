# LeetCode Clone

A full-stack LeetCode clone built with Next.js, Node.js, Express, MongoDB, and Tailwind CSS.

---

## 🚀 Features

- User Authentication
- Solve Coding Problems
- Responsive UI
- Discussion Section
- Admin Problem Management
- Test Case Execution
- Difficulty Levels
- Protected Routes
- Modern Landing Page

---

## 🛠 Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
